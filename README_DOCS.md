## 🎯 使用流程建议

### 对于教师

1. **阅读 SCHEDULE.md**（10 分钟）
   - 了解整个课程的时间分配
   - 制定 6 周的教学计划
   - 确定每堂课的内容

2. **参考 EXPERIMENT_GUIDE.md**（30 分钟）
   - 准备每个 Phase 的讲义
   - 了解学生的具体任务
   - 准备示例代码和演示

3. **打印 QUICK_REFERENCE.md**（给学生）
   - 学生可快速查阅
   - 减少开会提问时间

### 对于学生

1. **快速开始** （QUICK_REFERENCE.md 前 5 分钟）
   - 快速搭建开发环境

2. **阅读 EXPERIMENT_GUIDE.md 的对应 Phase**（10-20 分钟）
   - 理解本阶段的目标和任务
   - 查看参考代码片段

3. **在线编码和调试**（2-4 小时）
   - 遇到问题时查看 QUICK_REFERENCE.md

4. **验证和测试**（30 分钟）
   - 运行自测命令验证实现

## 🎓 实际教学建议

### 第一堂课
1. 给学生发 QUICK_REFERENCE.md 的"快速开始"部分
2. 让学生独立配置环境（15 分钟）
3. 讲解 EXPERIMENT_GUIDE.md 的"实验概述"（15 分钟）
4. 讲解项目结构（SCHEDULE.md 中的表格）（10 分钟）

1. 开始时，回顾上堂课的检查点
2. 讲解本堂课的内容（对应 EXPERIMENT_GUIDE.md 的某个 Phase）
3. 学生编码（参考 QUICK_REFERENCE.md）
4. 结束时，运行自测命令验证

### 期末答辩
1. 学生准备 5 分钟的技术讲解（参考 EXPERIMENT_GUIDE.md 的架构部分）
2. 查看学生的代码（对照 SCHEDULE.md 的检查点）
3. 评阅报告（按 SCHEDULE.md 的评分细则）
